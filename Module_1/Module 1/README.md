# COVID-19 Data Analysis in India

This project uses Python to explore COVID-19 data from India and create a few charts.

## Files
- `task1.ipynb` – notebook with the code and charts
- `requirements.txt` – required Python libraries

## Run the project

1. Install the libraries:
   ```bash
   pip install -r requirements.txt
   ```
2. Open `task1.ipynb` in Jupyter Notebook or Google Colab.
3. Run the cells from top to bottom.

The notebook downloads the dataset from Kaggle using `kagglehub`, so internet access is needed.

## Libraries
Pandas, NumPy, Matplotlib, Seaborn, and KaggleHub.

## Dataset
[Kaggle: COVID-19 in India](https://www.kaggle.com/datasets/sudalairajkumar/covid19-in-india)
